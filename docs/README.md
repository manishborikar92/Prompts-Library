## 🎨 Project Vision

**PromptBase** is an AI-powered prompt management platform that allows developers to:
- 🔍 Search through 58+ curated AI prompts
- ✏️ Create and edit custom prompts
- 🤖 Get AI-powered suggestions (Google Gemini)
- 📚 Organize prompts in collections
- 🔗 Share prompts with teams
- 📊 Track usage analytics

## 🚀 Quick Start

```bash
# 1. Clone repository
git clone https://github.com/manishborikar92/Prompts-Library.git
cd promptbase

# 2. Install dependencies
npm install

# 3. Set up environment variables
cp .env.example .env.local
# Edit .env.local with your credentials

# 4. Run database migrations
npm run db:migrate

# 5. Start development server
npm run dev
```

Visit http://localhost:3000
