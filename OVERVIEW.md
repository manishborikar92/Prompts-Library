## 🚀 How to Use

### Using the Master File
1. Open `AI-Prompts-Master-Consolidated.md`
2. Use the table of contents to navigate
3. Search for keywords using Ctrl+F / Cmd+F
4. Copy the prompt you need
5. Replace placeholders like `[FILE_NAME]`, `[PROJECT]` with your values

### Using Individual Files
1. Navigate to `individual-prompts/`
2. Browse the numbered category folders
3. Open the specific prompt file you need
4. Each file contains:
   - Prompt title
   - Category reference
   - Complete prompt text
5. Copy and customize for your use case
