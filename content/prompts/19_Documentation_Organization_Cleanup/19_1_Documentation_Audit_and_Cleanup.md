# 19.1 Documentation Audit and Cleanup

**Category:** 19. Documentation Organization & Cleanup

---

```
Review all Markdown (.md) files in the docs/ directory related to [TOPIC].

There are many files with duplicated content, and some should likely be removed or consolidated.

Perform the following tasks:

1. **Identify Important Files**:
   - Files that provide complete knowledge
   - Files with full understanding of the topic
   - Files with comprehensive implementation details
   - Files with unique, valuable information

2. **Identify Unnecessary Files**:
   - Files with duplicated content
   - Files with partial or incomplete information
   - Files that are outdated or superseded
   - Files with redundant information

3. **Analysis Criteria**:
   - Completeness of information
   - Accuracy and currency
   - Uniqueness of content
   - Quality of explanations
   - Practical value

4. **Recommendations**:
   - Provide a categorized list indicating files to **keep**
   - Provide a categorized list indicating files to **delete**
   - Suggest consolidation opportunities
   - Recommend renaming for clarity

5. **Consolidation Plan** (if applicable):
   - Outline which files should be merged
   - Suggest structure for consolidated documentation
   - Note any content that needs updating
```
